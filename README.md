# html-para-prova-Aghartazone
trabalho para resoluçao da avaliaçao da materia de desenvolvimento front end ("aghartazone" pois agharta remete a uma terra magica e fantastica de grande vislumbre, igual a arte) o trabalho consiste em um repositorio de imagens para artistas e fans de arte, contendo diferentes obras e artistas de diferentes periodos, feito inteiramente em html. 
o trabalho utiliza os requisitos destacados:
-De 3 a 5 páginas com  Navegação fluida, menu presente em todas com qualidade nos conteudos;
-Estrutura semântica completa  header, nav, main, section, article, aside, footer;
-Tabela 3x3 com dados reais  Com pelo menos um colspan ou rowspan, conforme sua escolha;
-Formulário avançado  type="date", type="file" ou type="range", datalist, required, placeholder;
-Details e summary  Em pelo menos 2 páginas;
-Figure e figcaption  Em pelo menos 2 páginas;
-Marcação avançada: abbr, mark, del, ins, blockquote, cite, progress, meter;
-audio ou video local  Arquivo real na pasta do projeto;
-Organização em pastas  na raiz do projeto html/, img/, audio/, video/;
-README no repositório  Explicando o projeto;
-Sem CSS  Nenhum style=, <style>, <center>, cellpadding, align em tabelas.
